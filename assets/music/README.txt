Optional custom invasion music.

The game ships with original music generated live in the browser. To replace an invasion theme with your own audio,
add an MP3 here (for example loki.mp3) and list it in tracks.json, e.g. {"loki": "assets/music/loki.mp3"}.
It then plays from the start of that variant's entrance cutscene and loops through the event.
Variants: swarm, giant, loki, ufo.

Only add audio you have the rights to use publicly. Do not add music ripped from YouTube or other services.
Copy the files into dist/assets/music as well so the Railway server serves them.
